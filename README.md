# 3D-Render
A 3D rendering program built from nothing but JavaScript, control over individual pixels (no fancy canvas functions were used), and my own linear algebra knowledge. It isn't well optimized, but I wanted to know I can make a 3D renderer so I did.

Use WASD to move in the horizontal plain, space and shift to move vertically, and arrow keys to turn.
Other shapes (I made cubes and tetrahedrons, but others can be made from the same object format) can be added in the "setup" function.
